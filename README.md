# Лендинг «Ведущая Оксана Гайчук» — Шелехов / Иркутск

Одностраничный сайт ведущей мероприятий (юбилеи, свадьбы, корпоративы, выпускные).
Готов к публикации: статический HTML + отдельные CSS и JS, без сборки и зависимостей.

## Структура
```
index.html            — страница (10 блоков), мета-теги, Open Graph, JSON-LD (Person, EntertainmentBusiness, FAQPage)
css/style.css         — стили, адаптив 320–1920 px
js/main.js            — бургер-меню, слайдер отзывов (стрелки, точки, свайп, клавиатура), видео, форма → WhatsApp
img/                  — оптимизированные фото (WebP + JPG, 2 размера), постеры видео, иконки, og-image
video/                — сжатые ролики (H.264, faststart, загрузка только по нажатию)
robots.txt, sitemap.xml, site.webmanifest, favicon.svg
llms.txt              — GEO: сводка для ИИ-поисковиков (Алиса/Нейро, ChatGPT, Perplexity)
seo/semantic-core.md  — семантическое ядро и план продвижения
```

## Блоки
1. Первый экран — «А гости скучать не будут?» / «Нет.»
2. Знакомство и цифры (с 2012 г., 1000+ праздников, 10–250 гостей, 80% по рекомендации)
3. Какие праздники веду + новогодние корпоративы
4. Стиль ведения: чего не будет / что будет + цитата
5. Фото и видео
6. Чем помогу бесплатно
7. Отзывы (слайдер)
8. Как забронировать (4 шага)
9. Частые вопросы
10. Контакты и форма «Свободна ли дата» (открывает WhatsApp с готовым текстом)

## Перед публикацией
- Заменить домен `oksana-gaychuk.ru` на настоящий: index.html (canonical, og, JSON-LD), robots.txt, sitemap.xml, llms.txt.
- **Отзывы в блоке 7 — шаблоны.** Заменить реальными отзывами клиентов (с их согласия).
- Блок с картой не добавлен: точного адреса нет, ведущая работает с выездом. Если появится адрес/офис — добавить карту Яндекса в блок «Контакты».
- Шрифты (Yeseva One, Golos Text, Marck Script) подключены с Google Fonts без блокировки отрисовки; при желании можно разместить локально.

## Совместимость
Chrome, Safari (iOS 13+), Firefox, Edge, Samsung Internet, Яндекс Браузер. Учтены safe-area iPhone, `playsinline` для видео на iOS, `prefers-reduced-motion`, видимый фокус клавиатуры.
